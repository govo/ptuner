## App Store 3.1.2 拒审修复：描述底部补 EULA 链接

- 背景：提交后被以 3.1.2（Business: Payments - Subscriptions）拒审，要求在 iOS 与 macOS 每种语言的商店描述底部加 Apple 标准 EULA 链接。
- 改动：9 个语言（de-DE/en-US/es-ES/fr-FR/it/ja/ko/zh-Hans/zh-Hant）的
  `PTuner/fastlane/metadata/<locale>/description.txt` 末尾统一追加：
  段落标题（本地化）+ 一句"依据 Apple 标准最终用户许可协议（EULA）授权使用" + URL
  `https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`。
  两个平台共用同一份 metadata，改一次 iOS + macOS 同时生效。
- Fastfile：新增 `EULA_URL` 常量与 `eula_footer_errors()`，并入 `validate_version_metadata`；
  `upload_metadata` / `upload_metadata_macos` 上传前先跑校验，任一语言缺链接直接中止。
- 文档：`fastlane/metadata/README.md` 增加"EULA 段落（必填）"一节；
  `doc/marketing/app-store-listing-zh-en.md` 补中英文 EULA 段落与第四节说明。
- 待办：ASC 上传需跑 `fastlane ios upload_metadata` 与 `upload_metadata_macos`（需 API Key 环境变量）。
- 风险提示：代码里付费墙用 RevenueCatPaywallKit，官方 3.1.2 也要求应用内购买页展示 Terms/Privacy 链接，
  该链接需在 RevenueCat 面板配置，代码中未见硬编码。
