# 专业调音器 App 产品需求文档（PRD）

**产品平台：** iOS / macOS
**产品定位：** 支持单音调音、多音同时调音、和弦识别及自定义调弦的专业乐器调音工具。

## 一、产品概述

### 1.1 产品目标

开发一款面向音乐爱好者及专业音乐人的调音器 App。

产品不仅支持传统的单音调音，还支持同时检测多个音高、识别和弦，以及针对不同乐器提供相应的调音方式。

产品应具备专业调音设备的精准视觉反馈，同时保持简洁、直观的操作体验。

### 1.2 核心功能

1. **单音调音：** 检测单个音高，显示音名、频率及音准偏差。
2. **多音调音：** 同时检测多个音高，分别显示各音的音准状态。
3. **和弦识别：** 识别当前演奏的和弦并显示和弦名称。
4. **乐器调音：** 根据选择的乐器及调弦方式显示对应的目标音高。
5. **自由调音：** 不受乐器和弦数限制，识别任意音高。
6. **自定义调弦：** 允许用户创建、编辑、保存自己的调弦配置。
7. **乐器管理：** 管理内置乐器、自定义调弦及收藏。
8. **专业设置：** 支持参考音高、音准显示精度、音频输入设备等设置。
9. **Pro 状态：** 展示当前用户的 Pro 权益及订阅信息。

# 二、整体页面结构

App 包含以下主要页面：

1. 调音器主页
2. 乐器选择页面
3. 乐器管理页面
4. 自定义调弦编辑页面
5. 设置页面
6. Pro 信息页面
7. 音频输入设备选择页面（macOS）

其中，**调音器主页是核心操作页面**。

用户应能够在主页直接完成调音，不需要频繁进入其他页面。

# 三、调音器主页

## 3.1 页面布局

主页采用三个主要区域。

### 上方：音准可视化区域

用于展示实时检测结果。

包含：

- 当前检测到的音名
- 音高频率（Hz）
- 音准偏差（Cents）
- 音准指示器
- 多音检测结果
- 和弦识别结果

可视化区域根据当前工作模式调整显示内容。

### 中间：乐器选择区域

展示当前选择的乐器及调弦方式。

例如：

吉他 · 标准调弦
E A D G B E

点击后进入乐器选择页面。

旁边提供乐器管理入口。

### 下方：多音调音控制区域

包含：

- 多音调音开关
- 同时检测音数设置
- 当前检测状态

关闭多音时，进入单音调音状态。

打开多音时，允许同时检测多个音高。

用户可以指定最大同时检测音数，例如 2、3、4、5、6 个或更多。

该数量表示最多显示或检测的目标音数量，不要求每次必须检测到相同数量。

# 四、调音模式

## 4.1 单音调音

默认调音模式。

### 界面内容

以大型音准指示器作为主要视觉元素。

显示：

- 当前音名，例如 E2
- 当前频率，例如 82.41 Hz
- 当前音准偏差，例如 -3.2 cents
- 音准指针或动态指示条

### 视觉反馈

音准偏低时，指示器向左偏移。

音准偏高时，指示器向右偏移。

接近目标音准时，使用绿色等明确的视觉反馈。

调音完成时，显示稳定的音准状态。

### 乐器关联

选择具体乐器时，根据该乐器的调弦配置显示对应的目标音。

例如选择吉他标准调弦：

E2、A2、D3、G3、B3、E4。

用户可以看到每根弦的目标音及当前状态。

当检测到某根弦的音高时，自动突出显示对应的弦。

### 自由调音

当选择自由调音时，不限定乐器及目标弦。

直接显示当前检测到的音高及其相对于最近标准音的偏差。

## 4.2 多音调音

用户打开多音开关后进入多音模式。

### 界面内容

同时展示多个检测到的音高。

每个音高具有独立的：

- 音名
- 频率
- 音准偏差
- 音准状态指示器

### 显示方式

根据音数自动调整布局。

例如同时检测六根吉他弦时，显示六个独立的音准指示器。

每个指示器分别显示对应弦的调音状态。

已调准的音使用绿色标识。

偏高或偏低的音使用不同的视觉反馈。

### 最大检测音数

用户可以设置最大同时检测音数。

例如：

最大检测数：6

当输入音高数量超过设置值时，界面最多显示六个有效检测结果。

### 乐器关联

选择具体乐器时，优先按照该乐器的目标调弦顺序排列显示。

例如吉他按照第六弦至第一弦的顺序展示。

自由调音模式下，按照音高由低到高排列。

## 4.3 和弦识别

和弦识别作为独立的显示模式。

用户可以在主页顶部切换至和弦识别。

### 界面内容

突出显示识别到的和弦名称。

例如：

C
Am
G7
Em7

同时显示：

- 和弦名称
- 当前识别到的组成音
- 各组成音的音名
- 和弦识别状态

### 交互要求

当用户弹奏和弦时，界面实时更新识别结果。

当和弦发生变化时，自动更新和弦名称。

当无法确定和弦时，显示等待识别或未识别状态，不强制显示错误的和弦名称。

# 五、乐器选择页面

## 5.1 页面目标

让用户快速选择乐器及对应调弦方式。

## 5.2 页面布局

页面顶部提供搜索框。

下方提供乐器分类：

- 收藏
- 吉他
- 贝斯
- 尤克里里
- 其他乐器
- 自定义

页面优先展示收藏的乐器及调弦配置。

## 5.3 乐器列表

每个乐器配置显示：

- 乐器名称
- 调弦方式名称
- 对应音名
- 收藏状态

例如：

吉他 · 标准调弦
E A D G B E

吉他 · Drop D
D A D G B E

吉他 · 全降半音
Eb Ab Db Gb Bb Eb

吉他 · Drop D 全降半音
Db Ab Db Gb Bb Eb

点击某个配置后，立即将其设为当前调音目标，并返回调音器主页。

## 5.4 收藏功能

每个乐器配置旁提供收藏按钮。

收藏后：

- 出现在收藏分类
- 在乐器选择列表中优先展示
- 可以随时取消收藏

收藏功能同时适用于内置调弦和自定义调弦。

## 5.5 自由调音入口

提供独立的「自由调音」选项。

选择后不限定乐器、弦数及预设调弦。

# 六、乐器管理页面

## 6.1 页面目标

集中管理乐器、调弦配置及收藏内容。

## 6.2 功能

支持：

1. 浏览所有内置乐器
2. 浏览各乐器的调弦配置
3. 收藏或取消收藏
4. 创建自定义调弦
5. 编辑已有自定义调弦
6. 删除自定义调弦
7. 复制现有调弦配置进行修改

内置调弦配置不可直接修改或删除。

用户可以通过复制功能创建新的自定义版本。

## 6.3 列表组织

按照乐器类型分组。

每个乐器下可包含多个调弦配置。

例如：

吉他

- 标准调弦
- Drop D
- Open G
- 全降半音
- 自定义调弦 A

贝斯

- 四弦标准调弦
- 五弦标准调弦
- 自定义调弦 B

# 七、自定义调弦编辑页面

## 7.1 页面目标

允许用户建立任意乐器的自定义调弦配置。

## 7.2 基本信息

用户可以设置：

- 调弦名称
- 所属乐器类型
- 弦数
- 每根弦的目标音高

例如：

名称：我的 Drop D 降半音
乐器：吉他
弦数：6

## 7.3 弦数管理

支持用户自行设置弦数。

允许：

- 增加弦
- 删除弦
- 调整弦的顺序

不将自定义调弦限制为传统六弦吉他。

## 7.4 单根弦设置

每根弦可以独立设置：

1. 音名，例如 C、D、E、F、G、A、B
2. 升降音，例如 C#、Eb
3. 八度，例如 E2、A3
4. 音分偏移（Cents）

### 音分偏移

允许用户在标准音基础上进行微调。

例如：

E2：-5 cents
A2：0 cents
D3：+3 cents

用户可以输入正数或负数。

音分偏移应直接影响该根弦的目标音准。

## 7.5 保存与管理

用户完成编辑后可以保存配置。

保存后的配置：

- 出现在对应乐器分类
- 出现在自定义分类
- 可以收藏
- 可以再次编辑
- 可以删除

编辑时提供取消及保存操作。

# 八、设置页面

## 8.1 基础设置

### 参考音高

默认使用 A4 = 440 Hz。

允许用户调整参考音高。

例如：

432 Hz
440 Hz
442 Hz

也允许手动输入其他参考频率。

该设置影响所有调音模式。

### 音准显示精度

允许设置音准显示的精细程度。

例如：

- 整数 Cents
- 0.1 Cents
- 更高精度（如支持）

### 指示器显示方式

提供不同的音准可视化形式。

例如：

- 指针式
- 横向音准条

用户可以根据个人偏好选择。

### 稳定度

提供音准显示稳定度选项。

例如：

- 快速
- 平衡
- 稳定

用于满足快速调音与稳定读数的不同使用需求。

## 8.2 音频输入设置

### iOS

显示当前使用的音频输入来源。

### macOS

允许用户选择 Core Audio 输入设备。

例如：

- Mac 内置麦克风
- USB Audio Interface
- 其他可用音频输入设备

当选择的设备不可用时，界面应明确提示。

## 8.3 Pro 信息

设置页面提供独立的 Pro 信息入口。

显示：

- 当前 Pro 状态
- 当前订阅类型
- 有效期或到期时间（如适用）
- 升级 Pro 入口
- 恢复购买入口

如果用户已经拥有 Pro 权益，应清楚显示已激活状态。

如果用户未拥有 Pro 权益，则展示升级入口。

具体哪些功能属于 Pro，由产品后续确定。

## 8.4 其他信息

包括：

- App 版本
- 关于 App
- 隐私政策
- 使用条款

## 9.1 普通用户

提供：

- Pro 功能介绍
- 升级 Pro
- 恢复购买

## 9.2 Pro 用户

显示：

- Pro 已激活
- 当前权益类型
- 有效期（如适用）
- 订阅管理入口（如适用）

# 十、macOS 页面适配

macOS 与 iOS 保持一致的功能结构和视觉语言。

但需要针对桌面操作进行适配。

## 10.1 主界面

允许使用更宽的布局。

多音调音时，可以横向排列多个音准指示器。

乐器选择和设置可采用侧边栏或弹出面板。

## 10.2 音频设备

提供清晰的输入设备选择界面。

用户能够查看并切换当前可用的 Core Audio 输入设备。

## 10.3 窗口适配

界面需要适应不同窗口大小。

窗口缩小时，自动调整音准指示器布局。

重要信息始终保持可见。

# 十一、视觉设计要求

## 11.1 整体风格

采用专业音乐设备风格。

参考专业调音单块、机架式调音设备及现代数字音频软件的设计语言。

整体要求：

- 简洁
- 专业
- 高对比度
- 易读
- 适合舞台及弱光环境

优先采用深色界面。

## 11.2 音准指示器

音准指示器是整个产品最重要的视觉元素。

应具备：

- 清晰的中心零点
- 明确的正负音分刻度
- 实时动态反馈
- 调准状态突出显示
- 偏高、偏低状态容易区分

可参考专业 Strobe Tuner、指针式调音器及 LED 音准指示器的视觉形式。

## 11.3 多音显示

多个音高同时出现时，应确保：

- 每个音高具有独立显示区域
- 音名清晰
- 音准偏差容易比较
- 已调准状态明显
- 不同音高之间不会产生视觉混淆

## 11.4 颜色规范

建议：

- 深色：主要背景
- 绿色：音准正确
- 黄色或橙色：音准存在偏差
- 红色：偏差较大
- 青色：选中状态及主要交互元素

颜色不应成为判断音准的唯一依据，还应结合位置、数字及其他视觉状态。

# 十二、主要用户操作流程

## 12.1 普通吉他调音

打开 App → 选择吉他标准调弦 → 弹奏单根弦 → 查看音准偏差 → 调整琴弦 → 完成调音。

## 12.2 多音吉他调音

打开 App → 选择吉他 → 打开多音 → 设置最大检测音数 → 同时拨动多根弦 → 查看各弦音准 → 分别调整。

## 12.3 自由调音

打开 App → 选择自由调音 → 弹奏任意音高 → 查看检测结果。

## 12.4 和弦识别

打开 App → 切换和弦识别 → 弹奏和弦 → 查看和弦名称及组成音。

## 12.5 创建自定义调弦

进入乐器管理 → 新建自定义调弦 → 设置名称和弦数 → 设置每根弦的音高及音分偏移 → 保存 → 选择该调弦进行调音。

## 12.6 收藏常用调弦

进入乐器选择 → 找到目标调弦 → 点击收藏 → 该配置优先显示在收藏列表中。

# 十三、重要交互原则

1. **调音优先：** 用户打开 App 后，应能立即开始调音。
2. **减少操作：** 常用调弦能够快速切换，不需要反复进入设置。
3. **状态明确：** 用户始终能够知道当前选择的乐器、调弦方式和多音状态。
4. **实时反馈：** 音准变化应通过清晰、连续的视觉变化呈现。
5. **模式一致：** 单音、多音及和弦识别使用统一的视觉语言。
6. **自定义灵活：** 用户可以创建不受传统乐器调弦方式限制的配置。
7. **跨平台一致：** iOS 与 macOS 的核心功能及设置保持一致。
8. **专业但不复杂：** 普通用户能够直接使用，高级用户能够进一步调整参数。

## 14.1 第一阶段功能范围

完成：

- 调音器主页
- 单音调音界面
- 多音调音界面
- 和弦识别界面
- 乐器选择
- 乐器管理
- 收藏功能
- 自定义调弦
- 参考音高设置
- macOS 音频输入选择

## 14.2 页面验收要求

所有页面应具备完整的视觉状态及交互入口。

包括：

- 正常状态
- 未检测到音频状态
- 正在检测状态

用户应能够完成以下操作：

1. 选择乐器并进行单音调音。
2. 打开多音模式并设置最大检测音数。
3. 查看多个音高各自的音准状态。
4. 切换至和弦识别并查看识别结果。
5. 使用自由调音检测任意音高。
6. 收藏、取消收藏常用调弦。
7. 创建包含自定义弦数、音名、八度和音分偏移的调弦配置。

10. 在 macOS 上选择音频输入设备。
11. 查看当前 Pro 权益状态。

# 十五、AI 开发执行要求

本 PRD 作为产品功能和 UI 交互的主要依据。

开发过程中应遵循以下原则：

- 以用户操作流程组织页面及功能。
- 保持调音器主页简洁，避免堆积过多设置。
- 复杂配置集中放在乐器管理及设置页面。
- 所有调弦配置应使用一致的展示方式。
- 单音、多音、和弦识别之间的切换应清晰。
- 不应因为增加高级功能而影响基础调音体验。
- 所有可见的按钮、开关和操作入口都应具有明确功能。
- 不应添加 PRD 未定义的复杂功能。
- 未明确的产品行为应先确认，不自行扩大产品范围。

**最终产品目标：让用户像使用专业调音单块一样快速完成调音，同时拥有软件所提供的多音识别、和弦识别和高度自定义能力。**
