# 乐器配置说明

乐器与内置调弦统一由 `PTuner/PTuner/Resources/Instruments.json` 管理。新增或调整乐器只需要修改这个文件，不需要改 Swift 代码。

## 顶层结构

```json
{
  "families": [],
  "instruments": []
}
```

- `families`：乐器族，决定筛选条分组与配色。
- `instruments`：具体乐器及其全部内置调弦。

## 乐器族

```json
{
  "id": "chineseBowed",
  "nameKey": "中国弓弦",
  "shortNameKey": "中国弓弦",
  "tint": "#FF7A6B",
  "order": 30
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 稳定字符串 ID，乐器通过 `familyID` 引用，不要随意修改。 |
| `nameKey` | 本地化 key；简体中文直接使用该值作为显示名。 |
| `shortNameKey` | 筛选条上的短名称。 |
| `tint` | 十六进制识别色，格式 `#RRGGBB`。 |
| `order` | 排序值，越小越靠前。 |

## 乐器

```json
{
  "id": "erhu",
  "familyID": "chineseBowed",
  "nameKey": "二胡",
  "glyph": "bowed",
  "image": "instrument_erhu",
  "tint": "#FF7A6B",
  "defaultStringCount": 2,
  "featured": false,
  "order": 10,
  "tunings": []
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 稳定字符串 ID，会写入用户保存的自定义调弦，不要修改已发布乐器的 ID。 |
| `familyID` | 所属乐器族。 |
| `nameKey` | 本地化 key；简体中文直接使用该值作为显示名。 |
| `glyph` | 共享矢量轮廓，可选 `guitar`、`lute`、`bowed`、`zither`、`harp`。形态相近的乐器可以共用。 |
| `image` | 可选，Assets 中的图片名。图片存在时优先显示图片，不存在时自动回退到 `glyph`。同类乐器可以填同一个图片名。 |
| `tint` | 可选，乐器专属识别色；缺省时跟随所属族。 |
| `defaultStringCount` | 新建自定义调弦时的初始弦数。 |
| `featured` | 为 `true` 时在筛选条上单独占一个入口（吉他、贝斯、尤克里里）。 |
| `order` | 排序值，越小越靠前。 |
| `tunings` | 内置调弦列表。 |

## 调弦

```json
{
  "id": "erhu.DA",
  "nameKey": "D-A 标准定弦",
  "order": 10,
  "strings": ["D4", "A4"]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 全局唯一，内置调弦使用稳定字符串，不要与自定义调弦的 UUID 冲突。 |
| `nameKey` | 本地化 key；简体中文直接使用该值作为显示名。 |
| `order` | 同一乐器内的排序值。 |
| `strings` | 从最低音弦到最高音弦的绝对音名。支持 `C4`、`F#3`、`Bb2` 三种写法。 |

`strings` 的顺序约定：

- 常规弦乐器按物理弦号从大到小排列，例如吉他六弦到一弦是 `E2 A2 D3 G3 B3 E4`。
- 班卓琴等带高音持续弦的乐器，按物理弦号 5、4、3、2、1 排列，因此数组第一个音可能不是最低音。
- 齐特琴、坎侬琴等多弦乐器按实际物理弦序排列：旋律弦、伴奏弦、低音弦、次低音弦依次写入，不要求音高单调递增。
- 组内为八度关系的双弦需要写出每一根弦，例如十二弦吉他的 `E2 E3 A2 A3 ...`。
- 组内为同度关系的双弦或三弦只写一个目标音，例如曼陀林的 `G3 D4 A4 E5`；同组两根弦的目标音相同，无需重复。
- 乌德琴、布祖基琴等按“弦组”调音的乐器，每个弦组只写一个目标音。
- 古筝、伽倻琴等超过 12 根弦的配置会自动以网格方式展示，无需额外设置。

## 添加新乐器

1. 在 `instruments` 中追加一项，填写稳定 `id`、所属 `familyID`、名称与排序。
2. 在 `tunings` 中填写至少一条常见调弦。
3. 在 `Localizations.json` 的每种语言中补充 `nameKey` 与调弦名的译文；缺失时会回退到英文。
4. 如需专属图片，把图片放进 `Assets.xcassets`，并把资源名填到 `image`。图片缺失时不会报错，会回退到 `glyph`。

## 不在列表中的乐器

产品文档中的“自定义弦数模板”由现有自定义调弦功能承担；尺八属于管乐器，不纳入弦乐调音预设。
